# PHPtuto — Aprendo PHP desde cero

Repositorio de aprendizaje: aquí practico **PHP desde cero** con ejemplos pequeños.

## Requisitos

- PHP 8+ (`php --version`)

## Servidor de desarrollo

```bash
php -S localhost:8000
```

## Ruta

1. Sintaxis básica, variables y tipos.
2. Condicionales, ciclos y funciones.
3. Formularios (`GET`/`POST`) y sesiones.
4. Conexión a base de datos (PDO) y mini-proyecto.
